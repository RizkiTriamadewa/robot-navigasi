🚀 CARA SETUP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: Setup Database Utama
────────────────────────────────────────────────────────────────
1. Buka phpMyAdmin: http://localhost/phpmyadmin
2. Buat database baru: robot_dashboard
3. Import file: db.sql

STEP 2: Setup RBAC Tables
────────────────────────────────────────────────────────────────
1. Pilih database: robot_dashboard
2. Klik tab SQL
3. Import file: setup_rbac.sql
   (Ini akan membuat 5 tabel: users, roles, permissions, 
    role_permissions, audit_logs)

STEP 3: Login
────────────────────────────────────────────────────────────────
1. Buka: http://localhost/robot_dashboard/robot-navigasi/login.php
2. Login dengan salah satu akun demo:
   
   Username: admin       Password: admin123      (Super Admin)
   Username: operator    Password: operator123   (Operator)
   Username: viewer      Password: viewer123     (Viewer)
   Username: technician  Password: tech123       (Technician)

STEP 4: Akses Dashboard
────────────────────────────────────────────────────────────────
Setelah login, otomatis redirect ke:
http://localhost/robot_dashboard/robot-navigasi/index.php


🎯 NAVIGASI DASHBOARD (5 TAB)

TAB 1: MONITORING (Dashboard Utama)
────────────────────────────────────────────────────────────────
Fitur:
  ✅ Battery monitoring
  ✅ Kamera (Live FPV) dengan multi-camera support
  ✅ GPS Tracking & Interactive Map
  ✅ Jarak tempuh real-time
  ✅ Air keluar monitoring
  ✅ Sisa tangki
  ✅ Path tracking dengan canvas
  ✅ Control buttons (Up, Down, Left, Right)

  1. Gunakan control buttons untuk menggerakkan robot

  3. Klik "Simpan" untuk save session

────────────────────────────────────────────────────────────────
Fitur:
  ✅ Level Cairan (persentase & ml)
  ✅ Motion Detection (Moving/Idle)
  ✅ Posisi (X, Y, Z coordinates)
  ✅ Speed (current & average)
  ✅ Mode Operasi (Manual/Auto)
  ✅ Koneksi Internet (status, ping, quality)

Cara Pakai:
  1. Klik tab "Sensors" di header
  2. Lihat 6 sensor cards dengan data real-time
  3. Data update otomatis dari Firebase

TAB 3: LOGBOOK (Activity Logs)
────────────────────────────────────────────────────────────────
Fitur:
  ✅ Real-time activity logs
  ✅ 4 tipe log (Info, Success, Warning, Error)
  ✅ Statistics dashboard
  ✅ Filter by type

  ✅ Export to CSV

  2. Lihat logs real-time
  3. Filter by type: All, Info, Success, Warning, Error
  4. Klik "Export CSV" untuk download
  5. Klik "Clear Logs" untuk hapus semua (Admin only)

TAB 4: RIWAYAT (History)
────────────────────────────────────────────────────────────────
Fitur:
  ✅ Tabel history semua sesi robot
  ✅ Filter by day, month, year
  ✅ Data: Waktu, Baterai, Jarak, Air Keluar, Sisa Air

Cara Pakai:
  1. Klik tab "Riwayat" di header
  2. Pilih filter: Today, This Month, This Year, All
  3. Lihat history data sesi robot

TAB 5: LAPORAN (PDF Report)
────────────────────────────────────────────────────────────────
Fitur:
  ✅ Summary data sesi saat ini
  ✅ Download PDF report
  ✅ Include map screenshot

Cara Pakai:
  1. Klik tab "Laporan" di header
  2. Klik "Download PDF" untuk generate report


🔐 RBAC SYSTEM (Role-Based Access Control)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

4 USER ROLES:
────────────────────────────────────────────────────────────────

1. SUPER ADMIN (admin / admin123)
   ✅ Full system access
   ✅ Semua control buttons enabled
   ✅ Bisa control robot
   ✅ Bisa spray water
   ✅ Bisa save & reset session
   ✅ Bisa clear logs
   ✅ Bisa manage users (future)

2. OPERATOR (operator / operator123)
   ✅ Robot control & monitoring
   ✅ Control buttons enabled
   ✅ Bisa spray water
   ✅ Bisa save session
   ❌ Tidak bisa reset session (Admin only)
   ❌ Tidak bisa clear logs

3. VIEWER (viewer / viewer123)
   ✅ Read-only access
   ✅ Bisa view semua data
   ✅ Bisa generate PDF
   ❌ Semua control buttons DISABLED
   ❌ Tidak bisa control robot
   ❌ Tidak bisa spray water
   ❌ Tidak bisa save/reset session

4. TECHNICIAN (technician / tech123)
   ✅ Maintenance & logs
   ✅ Bisa view & export logs
   ✅ Bisa tambah maintenance log
   ❌ Control buttons DISABLED
   ❌ Tidak bisa control robot

📋 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

MASALAH: Tidak bisa login
SOLUSI:
  1. Pastikan setup_rbac.sql sudah dijalankan
  2. Cek tabel users ada: SELECT * FROM users;
  3. Pastikan password benar (case-sensitive)
  4. Clear browser cache (Ctrl+F5)

MASALAH: Control buttons disabled untuk Admin
SOLUSI:
  1. Logout dan login ulang
  2. Clear browser cache
  3. Cek role_permissions table
  4. Pastikan session memiliki permissions

MASALAH: Session timeout terlalu cepat
SOLUSI:
  1. Edit auth.php
  2. Function getSessionTimeout()
  3. Ubah return value (default: 1800 = 30 menit)

MASALAH: Firebase tidak connect
SOLUSI:
  1. Cek koneksi internet
  2. Cek Firebase config di index.php
  3. Pastikan Firebase Realtime Database aktif
