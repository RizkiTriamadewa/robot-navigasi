1. Buka phpMyAdmin: http://localhost/phpmyadmin
2. Buat database baru: robot_dashboard
3. Import file: db.sql
   (Schema sudah lengkap: users, roles, permissions, role_permissions,
    audit_logs, daily_logs, activity_logs)

STEP 2: Login
────────────────────────────────────────────────────────────────
1. Buka: http://localhost/robot_dashboard/robot-navigasi/login.php
2. Login dengan salah satu akun demo:
   
   Username: admin       Password: admin123      (Super Admin)
   Username: operator    Password: operator123   (Operator - role bawaan)
   Username: viewer      Password: viewer123     (Viewer - role bawaan)
   Username: technician  Password: tech123       (Technician - role bawaan)

   (bukan role sistem) sehingga bisa di-rename atau dihapus jika
   tidak dipakai. Hanya Super Admin yang berstatus role sistem.

TAB 6: ADMIN (Admin Management) 🆕
────────────────────────────────────────────────────────────────
Fitur:
  ✅ User Management (Create, View, Toggle Status)
  ✅ Role Management (Create / Rename / Delete role custom) 🟢
  ✅ RBAC Permission Management (Checkbox Matrix per page/aksi)
  ✅ Role-based Permission Assignment
  ✅ Real-time Permission Updates
  ✅ Audit Logging

Cara Pakai:
  1. Klik tab "Admin" di header (hanya Super Admin)
  2. BUAT USER BARU:
     - Isi form: Username, Nama, Email, Password
     - Pilih Role dari dropdown (otomatis ikut role yang ada di DB,
       termasuk role custom yang kamu buat) 🟢
     - Centang "User Aktif" jika ingin langsung aktif
     - Klik "Buat User"
  3. KELOLA USER:
     - Lihat daftar user di tabel
     - Klik "Aktifkan/Nonaktifkan" untuk toggle status
     - User nonaktif tidak bisa login
  4. KELOLA ROLE (Role Management) 🟢:
     - Isi nama role + deskripsi, lalu klik "Tambah Role"
     - Tabel role menampilkan badge tipe (Sistem / Custom) dan
       jumlah permission yang sudah aktif
     - Tombol "Edit" untuk rename / ubah deskripsi
     - Tombol "Hapus" hanya aktif untuk role custom yang tidak
       sedang dipakai user manapun
     - Role Super Admin = tipe Sistem, tidak bisa di-rename / hapus
  5. KELOLA PERMISSION:
     - Scroll ke panel "RBAC Permission Management"
     - Setiap role punya kotak akses (checkbox per permission /
       page) yang bisa kamu atur sendiri
     - Centang/uncheck permission untuk role apapun
     - Permission tersimpan otomatis (debounce 500ms)
     - Toast notification muncul saat berhasil
     - Super Admin: kotak terkunci & selalu full access
  6. TIPS:
     - User yang sedang login perlu logout/login ulang setelah
       permission berubah
     - Jangan nonaktifkan akun sendiri
     - Sebelum hapus role, pindahkan dulu user yang masih memakai
       role tersebut ke role lain

Permission Modules (kotak akses default):
  • monitoring - Akses dashboard monitoring
  • sensors - Akses sensor data
  • logbook - Akses activity logs
  • history - Akses riwayat
  • reports - Generate PDF reports
  • admin - Manage users & permissions
  • control_robot - Control robot movement
  • spray_water - Spray water function
  • save_session - Save session data
  • reset_session - Reset session
  • clear_logs - Clear all logs
  • export_data - Export data to CSV/PDF
  • view_audit - View audit logs
  • manage_users - Full admin access

Catatan: daftar di atas adalah permission default. Kamu bisa
menambah permission baru dengan INSERT ke tabel `permissions`,
dan otomatis akan muncul sebagai kotak akses baru di matrix.

🔐 RBAC SYSTEM (Role-Based Access Control)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ROLE BAWAAN + ROLE CUSTOM (UNLIMITED) 🟢
────────────────────────────────────────────────────────────────

Sistem mendukung jumlah role tak terbatas. Ada 1 role sistem
(Super Admin) yang TIDAK bisa diubah/dihapus, plus role-role
lain yang sepenuhnya bisa kamu kelola sendiri lewat tab Admin.

1. SUPER ADMIN (admin / admin123)  ← Role Sistem 🔒
   ✅ Top tier, full access by design
   ✅ Permission selalu full, tidak bisa di-uncheck
   ✅ Nama "Super Admin" tidak bisa di-rename
   ✅ Role tidak bisa dihapus
   ✅ Hanya Super Admin yang bisa membuka tab Admin
   ✅ Bisa buat / rename / hapus role custom

2. OPERATOR (operator / operator123)  ← Role Bawaan
   Default permission:
   ✅ Robot control & monitoring
   ✅ Bisa spray water, save session
   ❌ Tidak bisa reset session, clear logs, akses Admin
   📝 Bisa di-rename atau dihapus jika tidak dipakai

3. VIEWER (viewer / viewer123)  ← Role Bawaan
   Default permission:
   ✅ Read-only (lihat dashboard, sensors, logbook, history)
   ✅ Bisa generate PDF
   ❌ Semua control buttons disabled
   📝 Bisa di-rename atau dihapus jika tidak dipakai

4. TECHNICIAN (technician / tech123)  ← Role Bawaan
   Default permission:
   ✅ View & export logs, tambah maintenance log
   ❌ Tidak bisa control robot
   📝 Bisa di-rename atau dihapus jika tidak dipakai

5. ROLE CUSTOM (mis. QA Tester, Supervisor Lapangan, dll) 🟢
   ✅ Buat lewat tab Admin → Role Management
   ✅ Tentukan sendiri kotak akses (page/aksi) di
      RBAC Permission Management
   ✅ Bisa di-rename, dihapus (jika belum dipakai user),
      dan permission-nya bebas diubah kapan saja

📋 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

MASALAH: Tidak bisa login
SOLUSI:
  1. Pastikan db.sql sudah di-import ke database robot_dashboard
  2. Cek tabel users ada: SELECT * FROM users;
  3. Pastikan password benar (case-sensitive)
  4. Clear browser cache (Ctrl+F5)

MASALAH: Role custom yang baru dibuat tidak bisa dihapus
SOLUSI:
  1. Cek apakah masih ada user yang memakai role tersebut:
     SELECT username FROM users WHERE role_id = <id_role>;
  2. Pindahkan user-user itu ke role lain dulu, baru hapus role.
  3. Role sistem (Super Admin) tidak akan pernah bisa dihapus.

MASALAH: Permission Super Admin tidak bisa di-uncheck
SOLUSI:
  Itu by design. Super Admin selalu full access (top tier role).
  Kalau butuh akun "admin terbatas", buat role custom baru lalu
  pilih kotak akses sesuai kebutuhan.

MASALAH: Control buttons disabled untuk Admin
SOLUSI:
  1. Logout dan login ulang
  2. Clear browser cache
  3. Cek role_permissions table
  4. Pastikan session memiliki permissions

MASALAH: Obstacles tidak muncul di map
SOLUSI:
  1. Refresh halaman (F5)
  2. Clear browser cache
  3. Cek console untuk JavaScript errors
  4. Pastikan Canvas API supported di browser

MASALAH: Robot tidak berhenti saat menabrak obstacle
SOLUSI:
  1. Refresh halaman
  2. Cek console untuk errors
  3. Pastikan collision detection function loaded
  4. Test dengan arrow keys terlebih dahulu

MASALAH: Session timeout terlalu cepat
SOLUSI:
  1. Edit auth.php
  2. Function getSessionTimeout()
  3. Ubah return value (default: 1800 = 30 menit)

MASALAH: Firebase tidak connect
SOLUSI:
  1. Cek koneksi internet
  2. Cek Firebase config di index.php
  3. Pastikan Firebase Realtime Database aktif
