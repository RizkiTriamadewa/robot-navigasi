🚀 CARA MENGGUNAKAN (3 LANGKAH MUDAH)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

LANGKAH 1: Setup Database
──────────────────────────
  1. Buka phpMyAdmin (http://localhost/phpmyadmin)
  2. Pilih database: robot_dashboard
  3. Klik tab "SQL"
  4. Copy-paste isi file: setup_tables.sql
  5. Klik "Go"
  
  ATAU via MySQL CLI:
  mysql -u root -p robot_dashboard < setup_tables.sql


LANGKAH 2: Buka Dashboard
──────────────────────────
  Buka browser, ketik:
  http://localhost/robot_dashboard/robot-navigasi/index.php


LANGKAH 3: Akses Halaman Baru
──────────────────────────────
  Di header dashboard, klik:
  
  🟣 Tombol "Sensors" (warna ungu)
     → Membuka halaman Sensor Monitor
     
  🔵 Tombol "Logbook" (warna indigo)
     → Membuka halaman Logbook
  
  Atau akses langsung:
  http://localhost/robot_dashboard/robot-navigasi/sensors.php
  http://localhost/robot_dashboard/robot-navigasi/logbook.php

❌ Halaman blank/error 500
   → Pastikan XAMPP running (Apache + MySQL)
   → Cek db.php connection benar

❌ Firebase tidak connect
   → Pastikan internet aktif
   → Cek browser console untuk error

❌ Charts tidak muncul
   → Refresh halaman (Ctrl+F5)
   → Cek browser console

❌ Database error
   → Jalankan setup_tables.sql
   → Pastikan database robot_dashboard ada
